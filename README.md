# ChenMe × Halloween — 24秒 縦型プロモーション動画

キャラクター原画と商品パッケージを **一切AI再生成せず**、実ピクセルのまま合成して
モーションだけをコードで付ける方式で制作した 1080×1920 / 30fps / 24秒 の縦型プロモ。

## 成果物

| ファイル | 内容 |
|---|---|
| `out/chenme_halloween_promo.mp4` | 本編（H.264 + AAC、24.00秒、1080×1920 @30fps） |
| `out/chenme_halloween_promo_noaudio.mp4` | 無音版（BGM差し替え・SNS音源合わせ用） |
| `out/chenme_halloween_promo_preview.gif` | 確認用の軽量GIF |

## 構成（尺 24.0秒）

| 時間 | シーン | 内容 |
|---|---|---|
| 0.0–4.6s | オープニング | 月夜のハロウィン背景にキャラクターが上からバウンド着地。紙吹雪バースト＋「ハロウィン、はじまるよ！」 |
| 4.6–9.2s | 9分割グリッド | 参考画像2枚目のレイアウトを踏襲した3×3コマ割り。センター→外側へ順にポップイン、「TRICK or TREAT」。最後は光と共に外側へ飛散 |
| 9.2–16.2s | メインパート | 石畳の street を5層パララックスでスクロール。キャラがホップで進み、キャンディが降る。13.7sからハロウィンボトル（4枚目）が光条と共に上昇 |
| 16.2–17.9s | リビール | ボトルのラベルから白いブルームが画面全体へ。ハロウィンボトル→**実商品ボトル**へ位置・スケールを完全一致させたままクロスフェード |
| 17.9–24.0s | 商品紹介 | 純白背景に商品ボトルを静止表示。「ChenMe / ほぐほぐクリーム / 今日より明日。もっとスッキリ。」＋キャラが左下から登場 |

## 守った制約

- **横目（閉じ目）を完全維持** — キャラクターは1枚目のPNGをそのまま`<img>`として配置し、
  平行移動・回転・等方スケール（スカッシュ＆ストレッチ）しか掛けていない。表情を描き変える処理は一切なし。
- **商品パッケージを非破壊** — 3枚目のボトル画像は生成AIを通さず、元ピクセルのまま等倍系スケールで合成。
  ラベルの文字・イラストは原画のまま。最後の約6秒はボトルを完全静止で表示。
- **リビールの継ぎ目なし** — 4枚目（ハロウィンボトル）と3枚目（実商品）を、
  事前にボトルのバウンディングボックス基準で同一キャンバス（820×1440）へ座標合わせ済み。
  同一矩形上のクロスフェードなので、変形なしで「？ラベルが正体を現す」演出になる。
- 尺は 24.0 秒（指定の 15〜30 秒内）。

## 技術構成

```
assets/src/     入稿4点（無加工）
assets/build/   前処理済み素材
  character.png              原画の透明領域をトリム
  bottle_product.png         スクショの黒帯を除去し 820×1440 に正規化（ボトル実寸1.0倍）
  bottle_halloween_white.png 実商品とボトル位置が一致するよう整列
  bottle_halloween_cut.png   四隅からのフラッドフィルで白背景を除去（暗部シーン合成用）
assets/fonts/   M PLUS Rounded 1c (OFL)
render/scene.html  1フレームを完全に決定する window.render(t) を持つ決定論的シーン
render/render.mjs  Playwright + Chromium で t=i/30 ごとにスクリーンショット
audio/make_music.py  BGMをゼロから合成（1小節=2.30秒＝画の切り替わりと同期）
```

### 再現手順

```bash
pip3 install pillow numpy
node render/render.mjs                 # frames/f00000.jpg .. f00719.jpg
python3 audio/make_music.py            # audio/score.wav
ffmpeg -y -framerate 30 -i frames/f%05d.jpg -i audio/score.wav \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -movflags +faststart \
  -c:a aac -b:a 192k -shortest out/chenme_halloween_promo.mp4
```

一部だけ描き直す場合は `--from=210 --to=280` でフレーム範囲を指定できる。

### BGM

すべて合成音（外部素材なし）。1小節2.30秒（約104BPM）で、
2小節目=4.60s（グリッド）、4小節目=9.20s（street）、7小節目=16.10s（リビール）と
画の切り替わりが小節頭に来るように設計。16.2sのリビールにインパクト＋ベル、
前後にライザーとウーシュを配置。後半はマイナー→ブライトな響きへ転換。
