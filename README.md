# ChenMe × Halloween — 24秒 縦型プロモーション動画（3D）

2枚目の画像を**9カットの絵コンテ（台本）**として、その9カットを **リアルタイム3D（Three.js）で作画**した
1080×1920 / 30fps / 24.0秒 の縦型プロモ。BGMもゼロから合成。

キャラクターは3Dモデル化しつつ、**顔だけは原画のピクセルをそのまま貼っている**ため、
横目（閉じ目）の表情は720フレーム全部で原画と同一。商品パッケージも生成AIを一切通していない。

## 守った制約

- **横目（閉じ目）を完全維持** — 3Dの頭部は本物のジオメトリだが、眉・目・口・チークは
  原画から α 付きで抜き出した1枚（`assets/build/face_decal.png`）を頭部曲面へ平面投影して貼っている。
  表情を描き直す処理がパイプラインのどこにも存在しないので、崩れようがない。
- **商品パッケージを非破壊** — 3枚目の画像は生成AIを通さず、DOMレイヤーに等方スケールのまま合成。
  ラベルの文字・イラストは原画のピクセルそのもの。最後の約3秒は完全静止。
- **リビールの継ぎ目なし** — 4枚目（ハロウィンボトル）と3枚目（実商品）を、
  ボトルのバウンディングボックス基準で同一キャンバスへ事前整列済み（比率が 0.468 : 0.471 とほぼ一致）。
  同じ矩形の上でクロスフェードするだけなので、変形ゼロで「？が正体を現す」。
- 尺は 24.0 秒（指定の 15〜30 秒内）。

## 3Dの作り方

キャラクターも背景も外部の3Dアセットを使わず、すべてコードで組み立てている。

- **キャラ**（`render/lib/char.js`）: 原画（1194×1209px）を実測し、頭幅597pxを2.0単位として全パーツの比率を決定。
  頭は頬が張ったエッグ形にバーテックスを変形。フードは開いたキャップ＋ロールしたブリム。
  ポンポンは小球52個をゴールデンアングルで配置してマージし、実物のようなモコモコに。
  マテリアルはPhongの「ソフビ人形」寄りセッティング。
- **背景**（`render/lib/props.js`）: ジャック・オー・ランタン（リブをコサインで変形＋発光する顔テクスチャ＋内部ポイントライト）、
  石畳（Canvas生成テクスチャ）、家、コウモリ、キャンディ、月、星、空のグラデーションドーム。
- **ライティング**: 月光（寒色ディレクショナル）＋カボチャの暖色ポイントライト＋ピンクのリム＋
  キャラに追従する暖色キーライト（シャドウキャスター）。ACESトーンマッピング。
  商品カットだけはトーンマッピングを切って純白（#FFFFFF）を出し、DOMの商品プレートと完全に一致させている。

## BGM

すべて合成音（外部素材なし＝権利クリーン）。オルゴール＋グロッケン＋ピチカートの
ファンシー寄りアレンジ、Cメジャー、125BPM。カット点（2.70 / 5.40 / 7.80 / 10.20 / 12.40 / 14.80 / 16.80s）
それぞれにチャイムとウーシュのアクセントを配置。16.8sからライザー、19.4sのリビールで
ハープのグリッサンドとベルのクラスターが鳴り、後半はゆったり解決する。

## 再現手順

```bash
npm install three
pip3 install pillow numpy

node render/render3d.mjs            # frames3d/f00000.jpg .. f00719.jpg （約35分 / SwiftShader）
python3 audio/make_music.py         # audio/score.wav
ffmpeg -y -framerate 30 -i frames3d/f%05d.jpg -i audio/score.wav \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -movflags +faststart \
  -c:a aac -b:a 192k -shortest out/chenme_halloween_promo.mp4
```

一部だけ描き直す場合は `--from=234 --to=372` でフレーム範囲を、
`--probe=8.9,18.2` で任意時刻の静止画を出せる。
`render/render3d.mjs` は自前の静的サーバ（127.0.0.1:8099）を立ててから
Playwright + Chromium（WebGL2 / SwiftShader）で1フレームずつスクリーンショットする。
`window.render(t)` が1フレームを完全に決定する決定論的な設計なので、何度描いても同じ絵になる。
