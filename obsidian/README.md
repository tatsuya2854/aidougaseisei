# Obsidian vault drop-in

This folder is written to be opened directly as an Obsidian vault, or copied
into an existing one. Notes use YAML frontmatter, `#tags` and `[[wikilinks]]`.

Claude has no Obsidian connector in the remote session, so it writes here and
the repo carries it. Pull the repo, then either

* open `obsidian/` as a vault, or
* copy `obsidian/ChenMe/` into your vault.

From the next job on, read `[[ChenMe/00 プロジェクト索引]]` first.
