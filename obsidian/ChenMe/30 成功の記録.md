# 成功の記録

効いた技術。次回そのまま流用する。

## 決定論的レンダリング

`window.render(t)` が**時刻tだけで1フレームを完全に決める**。
乱数もアニメーション状態も持たない。Playwright で1フレームずつ
スクリーンショット → ffmpeg でエンコード。

**効いた理由**
- 任意のフレームを単独で再レンダーできる（部分修正が数分で済む）
- 差分レンダーが可能（潰しを直したとき、着地の前後だけ再描画した）
- プレビュー用の probe が本番と完全一致する

```bash
node render/render3d.mjs --probe=1.3,13.3      # 確認用
node render/render3d.mjs --fps=120             # 本番
node render/render3d.mjs --fps=120 --from=28 --to=155   # 部分修正
```

## オーバーラップ層（動きの質を決めた最大の要素）

各関節の「意図したポーズ」を `charXform(t)` が返し、その**履歴を畳み込んで**
遅れと揺り戻しを生成する。手付けではない。

```js
drag(k, tc)   // 指数カーネルで過去を加重平均 → 追従の遅れ
ring(k, f, d) // 2階微分に減衰サインを畳み込む → 本物のバネ応答
```

`charXform` が時間の純関数なので、履歴サンプリングも決定論的。
**部位ごとの遅れ時間**（実測で決めた値）：

| 部位 | drag | ring |
|---|---|---|
| 胸 | 0.035s | 弱 |
| 頭 | 0.085s | 中 |
| 肘・膝 | 0.065–0.085s | 中 |
| 足首 | 0.090s | 中 |
| **しっぽ** | 0.175s | 強（2軸） |
| **ポンポン** | — | 最強（floppy） |

これを入れるだけで「リグを動かしている」から「キャラが動いている」に変わる。

## 煙の中で1フレーム差し替え

製品ボトルを変形させずに切り替える方法。

1. 紫の煙が立ち上がってボトルを**完全に覆う**
2. 不透明になった**1フレームの中で** `img` を差し替え（ディゾルブなし）
3. 閃光＋衝撃波リングで煙を飛ばす

煙はオフスクリーンcanvasに**硬い輪郭の円**を重ねて描いてから合成する。
放射グラデーションだけで描くとエアブラシの靄になって安っぽい。

## 3Dボトルの質感

- 断面をスーパー楕円にしてロフト（押し出しの角柱にしない）
- `MeshPhysicalMaterial` + `clearcoat: 1`
- **白い樹脂を白背景で立体に見せる鍵は、左右の黒フラッグの映り込み**。
  環境マップに意図的に黒い塊を置く（`studioEnv()`）
- ラベルは前面の弧に**弧長で**巻く（印刷時のアスペクトが保たれる）

## フードの造形（キャップ型）

球殻に楕円の穴を開けると「ボールに穴」になる。正解は：

- 穴を**U字**にする（眉の上は半楕円、頬から下は幅一定で下に抜ける）
- → 顎がフードの下から出る。参照画像の構造と一致
- 穴の縁に掛かる頂点は**横方向に縁へ滑らせる**（グリッドのギザギザが消える）
- ライニング（茶色の内張り）は**上側だけ厚く**（前髪のライン）

## モーションブラー

120fps でレンダーして ffmpeg で2枚平均 → 60fps。
レンダラ側に手を入れないので壊れない。

```bash
ffmpeg -r 120 -i f%05d.jpg -vf "tblend=average,framestep=2" -r 60 out.mp4
```
