# アニメーション設計

## 二層構造

```
charXform(t, si)   →  「意図したポーズ」。時間の純関数。手で書く。
      ↓
makeOverlap(t)     →  履歴を畳み込んで遅れ・揺り戻しを生成。自動。
      ↓
poseCharacter()    →  リグに適用
```

**手で書くのは意図だけ。追従の遅れは一切手付けしない。**
これを分けたことで、9カット全部に一貫した「生き物っぽさ」が乗った。

## オーバーラップ層の中身

窓 `WIN = 0.46s` を `NS = 15` 点でサンプリング。

```js
drag(k, tc)  = Σ f(t−τ)·e^(−τ/tc) / Σ e^(−τ/tc)      // 追従の遅れ
ring(k,f,d)  = Σ f''(t−τ)·e^(−dτ)·sin(fτ) dτ         // バネの揺り戻し
```

`ring` は加速度を入力にした**減衰インパルス応答**なので、
急停止・急発進のときだけ揺れて自然に収まる。定常状態では0。

部位ごとの定数は [[30 成功の記録#オーバーラップ層]] の表を参照。

## 動きの原則（実装した箇所）

| 原則 | 実装 |
|---|---|
| 予備動作 | `bounce()` の crouch 相 (u < 0.22)、ヒーローの `anti` |
| 潰し・伸ばし | `squash` ＋ 縦加速度からの自動生成 |
| 追従・重なり | オーバーラップ層 |
| 円弧 | FKチェーンが自然に生む。ルートの軌道も放物線 |
| 詰め・伸ばし | `eOut/eIO/eBack` を使う。線形補間を使わない |
| 二次的な動き | しっぽ・ポンポン・耳 |
| 誇張 | 着地の潰し、跳躍の伸び |
| 演技 | 表情8種＋カットごとの芝居 |

## バウンス関数

```
u < 0.22           しゃがみ（squash が −0.24 まで深くなる）
0.22 ≤ u < 0.84    空中。放物線。踏切と着地で伸び、頂点で中立
u ≥ 0.84           着地の潰し −0.26 から減衰振動で戻る
```

`bounceLimbs()` が同じ位相で腕（振り上げ）と脚（抱え込み）を駆動する。

## 走りサイクル

`stepCycle(o, ph, amp, armAmp, knee)` — 矢状面。
脚が前後（`legLF/RF`）に振れ、後ろ脚の膝が畳まれ、腕が逆位相。
体は2倍の周期で上下、前傾。**左右に振るだけの「歩き」にしない。**

## カメラ

`orb(cx,cy,cz, radius, angle, camY, lookY, fov)` で被写体の周りを回る。
9カット中7カットで回り込む。ヒーローカットは約75度スイープ。

**画角の目安**（縦1080×1920、fov は垂直）
```
可視高さ ≈ 2 · d · tan(fov/2)
キャラ全長3.2＋ポンポンを収めるには 可視高さ 4.5〜5.5 が目安
fov 33 なら d ≈ 8〜9.5
```

> [!warning] three.js の fov は垂直。9:16では**横が厳しい**
> 横位置を決めてから縦を合わせる。
