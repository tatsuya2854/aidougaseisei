# キャラクター仕様

`render/lib/char3d.js`。全長 `H = 3.20` ワールド単位（足裏〜フード頂点）。

## 実測の出どころ

- `assets/poses/cut/stand.png`（722×778、足裏 y=776、中心線 x=248）
- `assets/src2/ref_cheer.png`（ポンポン持ちの決定稿。**比率はこちらを優先**）

換算：`world_y = (776 - src_y) * 3.20 / 776`

## 比率（丸くなりすぎないための基準）

> [!important] ここを外すと「丸々しすぎ」と言われる
> - 腕の直径 ÷ 顔幅 = **0.127**
> - 脚の直径 ÷ 顔幅 = **0.109**
> - 胴幅 ÷ 顔幅 = **0.53**
> - フード幅 ÷ 顔幅 = **1.12**（薄いキャップ。球殻にしない）
> - 顔のアスペクト（幅÷高さ）= **1.54**（横に広い）

## 顔テクスチャ（512×320、前面パッチに貼る）

眉・閉じ目・口・チークを canvas で描く。表情8種はこのテクスチャの差し替え。

| 要素 | 位置 | サイズ |
|---|---|---|
| 眉 | x = 256±126, y = 97 | 半幅66 / 半高26 / 線幅27 |
| 閉じ目 | x = 256±126, y = 180 | 半幅66 / 半高27 / 線幅25 |
| 口 | x = 256, y = 244 | 笑い口は半幅62×半高52 |
| チーク | x = 256±143, y = 234 | rx56 ry35 |

**口**はただの楕円ではなく、上辺が平らで下が丸い「グリン」形。
上唇のラインを別に引くと小さいサイズでも笑って見える。

## スケルトン

```
root
 └ hips ── chest ── neck ── head ── tail
    │        ├ 肩L/R ── 肘 ── 手 ── ポンポン
    └ 股L/R ── 膝 ── 足首 ── 靴
```

全関節3軸。ポーズAPIは `poseCharacter(root, P)`。
主なキー：`armL/armR`(Z=横に上げる) `armLF/armRF`(X=前後) `elbowL/R`
`legL/R`(Z) `legLF/RF`(X) `kneeL/R` `ankleL/R` `spine/spineX` `head/headX/headY`
`tail/tailX` `squash` `lean` `pitch` `poms` `pomL/pomR`

> 符号の約束：**右腕を横に上げる = +、左腕を横に上げる = −**
> （毎回間違えるので明記）
